# A Certificate Profile's issuance settings are copied; its name rules and its enabled state are checked live

A Managed Certificate requested through a Certificate Profile takes a copy of the profile's issuer, key algorithm, validity and starting Renewal Policy, and records which profile it came from. Editing the profile later, including pointing it at another issuer, changes none of the Managed Certificates already made from it. Two things are not copied. The profile's name rules, as they are now, bind a non-administrator's Name Change on such a Managed Certificate. Whether the profile is enabled is checked whenever something would be issued under it: while it is disabled, no Proposal is made or approved, no Name Change is proposed or approved, and no Renewal happens, automatic or asked for. Organization Administrators are held to the issuer's own limits, never to a profile's name rules, but a disabled profile stops them too. Their way out for one Managed Certificate is to detach it from its profile. It then keeps its copied settings and Owners and renews again as an ordinary Managed Certificate. Pre-approval is deliberately absent: every non-administrator's request through a profile is a Proposal an Approver decides.

We copy the settings that shape what is issued so that nobody's Certificate changes because someone else edited a profile, the same reason an Enrollment Profile's Device Certificates keep what they were issued with. Name rules stay live because a Name Change is a fresh request. Copying them would let a Managed Certificate keep a profile's past, looser rules. Not checking them at all would let a Name Change get around the profile. Disabling stops Renewal because "disabled" is meant to mean that nothing more is issued under the profile, not only that nothing new is requested.

Consequences: disabling a profile is disruptive. Every live Managed Certificate made from it stops renewing and will expire unless the profile is enabled again or the certificate is detached. The scheduler records the certificate as blocked and its Subscribers are told once. The web app's confirmation states how many certificates and pending decisions are affected. The API asks for no acknowledgement and documents the effect. Disabling is reversible, unlike an Enrollment Profile's. Revocation, downloads, Owner, Subscriber and Renewal Policy changes, and Archive never depend on the profile.
