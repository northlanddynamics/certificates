# Multi-organization from day one, with Better Auth owning identity

The platform is designed as hosted SaaS: unrelated companies are Organizations in one deployment, partitioned into Teams. All identity concerns (password + MFA, passkeys, OIDC, SAML, organizations, teams, roles, API keys) are delegated to Better Auth configured with organization and team support from the start, because retrofitting tenancy onto a single-org schema is far costlier than starting with it. Platform Operators create Organizations but see inside one only when explicitly invited into it; Better Auth's impersonation is enabled for Platform Operators with no additional guardrails (no Organization consent step), accepted as an operator-trust decision. Impersonation is not audited by default; a platform-wide setting can enable it.
